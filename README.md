# Jab-Judge-
A piezoelectric sensor-based boxing scoring system using  microcontrollers.By synchronizing impact timestamps from a boxing glove and headgear, the system distinguishes landed punches (HIT), blocked punches (BLOCKED), and unmatched head impacts (HEAD_ONLY). Includes Python-based scoring, real-time signal visualization, and CSV data logging.
